# Components wrap Base UI directly

Interactive behavior and accessibility come from `@base-ui/react` — focus management, keyboard handling, ARIA wiring, portals, dismissal — and the library adds only tokens and markup on top. There is no generator and no intermediate layer of pre-styled components: an atom imports the Base UI component it wraps, styles it with semantic tokens, and is the single home for that component's markup, variants, and styles. Every part of a compound component is wrapped, pass-through parts included, and exported as a named function; the barrel re-exports the file as a module namespace (`export * as Dialog`) that mirrors Base UI's anatomy (`Dialog.Root`, `Dialog.Trigger`, `Dialog.Popup`, …), so Base UI's documentation transfers one-to-one and consumers never import `@base-ui/react` themselves — the library owns the whole surface and can change what sits underneath.

**Considered options:** a generator that copies pre-styled components into the repo (shadcn/ui) was rejected: it layers a second vocabulary over Base UI's — its own token names, `data-slot` hooks, compatibility variants for two headless libraries — and leaves ownership of the generated code ambiguous (restyle it in place and upstream updates are lost; wrap it and each component has two homes). Styling Base UI per component with CSS Modules was rejected because the token contract is Tailwind classes and is lint-enforced there (ADR 0003).

**Consequences:** wrappers accept `className` only as a string — `cn()` flattens through clsx, which silently drops Base UI's state-callback form — and style state through Base UI's data attributes with Tailwind's native variants (`data-open:`, `data-disabled:`, `data-starting-style:`). Composition goes through Base UI's `render` prop (`<Dialog.Trigger render={<Button />}>`); links are never rendered as buttons, because Base UI enforces button semantics. Because a compound file exports nothing but its part components, `react-refresh/only-export-components` runs across the whole components tree: a namespace object would fail it, and so would a stray non-component export (a `cva` object, a hook) — the same thing that would silently degrade a file's Fast Refresh to a full reload. Base UI's own docs ship inside the package (`node_modules/@base-ui/react/docs/`); the `base-ui` skill carries the wrapping conventions.

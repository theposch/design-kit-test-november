# The type-style composites are the library's only type vocabulary

Library code styles type exclusively with the composite utilities in `src/theme/typography.css` — `type-body-*` (anything read), `type-label-*` (anything pressed, or naming a control) and `type-heading-*` (page structure). A composite fully determines family, size, line height, weight, and tracking, so one class names one complete type style; case and numeric variants remain composable modifiers on top. Lint enforces it: Tailwind's default text scale (`text-sm`), the bare size tokens (`text-body-sm` — internal plumbing), standalone weight utilities (`font-medium`), and standalone line height and tracking (`leading-*`, `tracking-*`) are all restricted classes in `src/**`. A unit test (`src/theme/typography.test.ts`) checks that every composite sets all five axes from its own variables, so a brand font retunes every style and skips none.

The composites are raw declarations, not `@apply`, and this is forced rather than stylistic: `@apply` cannot take a variable, so a composite built from `@apply font-medium` could never pick up a tunable per-register weight (`--body-weight`, `--label-weight`, `--heading-weight`). A second constraint pushes the same way — Tailwind's `--font-*` (family) and `--font-weight-*` (weight) namespaces both compile to `font-<name>`, so a register cannot own both axes through registered tokens. The `@theme inline` registrations stay as the public token surface; the composites read the underlying vars directly, and `lib/utils.ts` mirrors them for tailwind-merge (a unit test keeps the two in sync). The `type-*` prefix keeps the composites out of Tailwind's own `font-*` namespace — home of the family tokens (`font-body`) and the banned weight utilities — so a composite can never collide with either, and tailwind-merge gives them a class group of their own instead of masquerading as font-family entries.

Unlike the color palette — which `palette.css` wipes with `--color-*: initial` — the default text scale is deliberately **not** wiped: a wiped utility fails silently (Tailwind just stops generating the class), which is a hostile failure mode to impose on a consumer app. Enforcement lives in this repo's lint config instead. A new type style is a new composite in `typography.css`, not a weight utility at the call site.
